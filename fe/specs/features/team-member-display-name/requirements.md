# 기능 요구사항

## 기능 이름

비회원 팀원 표시 이름

## 목표

- 운영진이 가입하지 않은 용병·비회원 팀원을 이름과 구분으로 등록한다.
- 팀 명단, 경기, 통계, 회비에서 팀별 표시 이름을 일관되게 사용한다.

## 인수 기준

- OWNER·SUB_MANAGER만 비회원 팀원을 추가할 수 있다.
- 비회원 팀원은 `user_id` 없이 표시 이름과 MEMBER 또는 GUEST 역할로 저장된다.
- 가입 사용자는 생성·가입 시 계정 이름을 표시 이름으로 가진다.
- 비회원 팀원을 추가하면 종료되지 않은 예정 매치의 참여현황에 `PENDING` 상태로 등록된다.
